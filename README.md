### Mission control

I run **ZERACK**: a crew of AI agents that research, write, animate, edit and publish video, every day. I build the tools and the tests; the agents do the work, and every piece has to pass its checks before it ships.

**In orbit right now**

- 🎬 **Frutinovelas pipeline**: script → images → Grok animation → automatic montage → QA, running on a partner's own machine.
- 📺 **YouTube channels**: long-form history and daily shorts, measured on retention, CTR and stayed-to-watch.
- ✂️ **Live-stream clips factory**: picks the best moments, frames the face and writes the hook.
- 🛰️ **Partner portal and stack**: versioned rules, remote support with consent, auto-updates and rollback.

**Latest from the crew**

- A first-frame check that catches clips generated without their reference image: right image 0.98–0.99, wrong image ≤ 0.46, calibrated on 70 clips.
- Thumbnail rule learned from data: text that adds a fact the title doesn't say beats text that repeats it (4.2% vs ~1–2% CTR).
